# Котонаходиловка

## Использование

На странице появится окно `Котонаходиловка`.

- Введите имя или ID и нажмите `+` или Enter.
- Можно добавить сразу несколько целей через запятую: `Синеглазка, Ураган`.
- Регистр не важен: `синеглазка` и `Синеглазка` считаются одним именем.
- Снимите галочку у строки, чтобы убрать подсветку для этого кота.
- Нажмите `x`, чтобы удалить строку.
- `on/off` выключает или включает всю подсветку.
- Окно можно перетаскивать за верхнюю строку.
- Цвет подсветки меняется внизу окна: нажмите на цветную плашку, выберите цвет, затем кликните в любое место вне выбора, чтобы закрыть его.

Если цель из списка не найдена на текущей локации, окно покажет строку `Не найдены: ...`. Список, цвет и положение окна сохраняются в `localStorage` сайта.
